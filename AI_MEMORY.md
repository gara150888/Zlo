# Zlo — AI Memory (Cross-Session Context)

**This file is the AI's shared long-term memory for this repository. It exists so that no AI session
repeats work another session already did, re-litigates decisions, or re-tries dead ends.**

**Owner discipline: it is only useful if every session maintains it. Reading it is mandatory at the
start of work; updating it is mandatory before handing back.**

---

## Protocol — MANDATORY for every AI session

### 1. READ (start of session, before writing any code)

1. Read this file **in full** — all sections, not just the top.
2. Reconcile reality with this file:
   - `git log --oneline -10` — if work from "Session Log" is not committed, note it under
     "Uncommitted / In Flight" so you do not duplicate it.
   - `git status` — see above.
   - `git branch --show-current` — record it in "Session Log" entries you add.
3. Read `AGENTS.md` for stack/project rules; this file only covers session-to-session memory.

### 2. USE (during the session)

- Before starting any task, check **Do Not Repeat**, **Known Issues**, and **Decisions**. If your
  plan contradicts one of them, stop and either follow the recorded outcome or explicitly supersede
  it (rewrite the entry, mark it `SUPERSEDED <date>` and add the new reason).
- Use **Repo Map & Discovery Pointers** instead of re-exploring the repo from scratch.
- If you discover something a future session would waste time re-deriving, add it immediately
  (do not wait until the end of the session — you may be interrupted).

### 3. WRITE (end of session, before handing back)

1. Append exactly one entry to **Session Log** (newest on top) using the format below.
2. Rewrite **Handoff / Next Steps** from the perspective of a blind successor: what is in progress,
   what is the immediate next command/file, what is blocked and why.
3. Prune aggressively: this file must stay **under ~200 lines**. Move anything older than ~10
   sessions into git history (it is already committed) — delete rather than accumulate.
4. Never delete **Decisions** or **Do Not Repeat** entries; supersede them in place.
5. Include this file in the commit you make, or commit it separately:
   `git add AI_MEMORY.md && git commit -m "chore: update AI memory"`.
   An uncommitted memory file is invisible to the next session and to other machines.

### Session Log entry format

```
- `YYYY-MM-DD` · branch `<branch>` · <one-line task summary>
   Files: <package/paths touched>
   Outcome: <what now works / what was learned>
   Follow-up: <next step, or "none">
```

  Better Fullstack.
- **Package manager**: `bun` (1.3.14), bun workspaces + turborepo. Dependency versions live in the
  root `package.json` `catalog` and must be referenced as `catalog:` in workspace manifests.
- Workspaces: `apps/web` (Next 16 + React 19, Tailwind v4, shadcn-style UI) and `packages/api`,
  `packages/auth`, `packages/db`, `packages/env`, `packages/config`, `packages/zod`.

  target of `apps/server`, but no `apps/server` directory exists. Backend logic lives in
  `packages/api` (tRPC routers + `src/server/services/automation`). Trust the filesystem.
- **Commands** (root): `bun install`, `bun dev` (turbo dev), `bun build`, `bun test` (runs
  `--filter @Zlo/api test` only), `bun db:push`, `bun db:generate`, `bun check-types`
  (`turbo check-types`). Per-package: `bun run --filter <pkg> test`.
- **Auth**: better-auth, configured in `packages/auth`; a proxy middleware protects routes and
  redirects. Web app dev port is 3000.
- **Env**: `packages/env` validates env with zod; copy `.env.example` → `.env` per app/service
  before running database-backed services. `.env*.local` and `.env` are gitignored.
- **Renewals page** (`/renewals`): month-grid `RenewalsCalendar`
  (`components/dashboard/renewals-calendar.tsx`) + list toggle. State source is the URL:
  `?view=calendar|list&month=YYYY-MM&day=YYYY-MM-DD&days=7|30|60|90` (view also mirrored in
  localStorage key `zlo:renewals-view`). Occurrence math: `renewalOccurrencesInMonth()` in
  `apps/web/src/lib/subscription-metrics.ts`. `/calendar` is an unlinked placeholder stub.
- **SEO**: `apps/web/src/lib/seo.ts` owns the site origin (`BETTER_AUTH_URL`, trailing slash
  stripped, localhost fallback), title/description/keywords. Routes: `app/robots.txt`,
  `app/sitemap.xml` (public routes only — `/` and `/login`), `app/opengraph-image.tsx`
  (1200×630 via `next/og`, brand `#ff5e1f`). JSON-LD via `components/seo/json-ld.tsx`
  (escaped serialization) is emitted from the root layout. Client pages cannot export metadata —
  `/login` gets its title from a server `app/login/layout.tsx`.
- **Generator safety**: `bts.jsonc` owns the stack graph. Before recipe-owned edits run
  `create-better-fullstack recipes check --json`; use `doctor --json` before repairing drift.
  Managed regions are marked `<!-- <better-fullstack:recipes ...> -->` in `AGENTS.md`/`CLAUDE.md` —
  never hand-edit inside them.

## Known Issues / Tech Debt

- `bun test` at the root only covers `@Zlo/api`; web tests need `bun run --filter web test`
  (vitest + jsdom + Testing Library is not in the root `test` script).
- `packages/api` ships `dist/` and `.turbo/` outputs locally; gitignored, but they make the repo
  look stale/compiled when grepping. Prefer `src/`.
- `@Zlo/env` and `@Zlo/config` define no `check-types` script (so `turbo check-types` reports 5
  tasks, not 7) and only `web` defines `build` (so `turbo build` runs 1 task).
- **Turbo strict env mode**: any env var a task needs must be declared in `turbo.json`
  (`globalPassThroughEnv` / `globalEnv` / per-task `env`), otherwise Turbo silently strips it.
- **Stale `.next/types`**: `check-types`/`build` can fail on `.next/types/validator.ts`
  referencing a deleted route. Fix: delete `apps/web/.next/types` (a running dev server locks
  `.next/dev/cache`, so a full `.next` deletion fails on Windows).
- `packages/db/src/server/crypto.ts` (+ the `@Zlo/db/server` barrel) is dead Instagram-pivot code
  reading `INSTAGRAM_ENCRYPTION_KEY`. Nothing imports it.
- `/calendar` is an unlinked placeholder page; the renewal calendar now lives on `/renewals`.
- **typedRoutes gotcha**: with `typedRoutes: true`, both `Link href` and `router.push/replace`
  hrefs reject a bare `string` — cast to the `AppRoute` union in `@/lib/routes` (the query string
  is runtime-only; `router.*(href, { scroll: false })` keeps scroll position).
